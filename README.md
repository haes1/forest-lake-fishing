# Лесное озеро — MVP

Оригинальный браузерный прототип рыболовного симулятора для компьютера и телефона.

## Что уже работает

- настоящая 3D WebGL-сцена на Three.js: вода с волнами, берег, сосны, мостик, удилище, леска и поплавок;
- поплавочная ловля: заброс → ожидание → поклёвка → подсечка → вываживание;
- активное вываживание с контролем натяжения и дистанции до берега;
- 8 видов рыбы с разным весом, сопротивлением и ценой;
- 3 места ловли с открытием по уровню;
- улучшение удилища, лески и наживки;
- садок, продажа улова и альбом рекордов;
- локальное сохранение прогресса в `localStorage`;
- адаптивное управление мышью, перетаскивание камеры и сенсорные кнопки для мобильного.

## Запуск

Можно открыть `index.html` напрямую в браузере. Для проверки через локальный сервер:

```bash
python3 -m http.server 8080
```

Затем открыть `http://localhost:8080` из папки проекта.

## Следующий этап для Яндекс Игр

Перед публикацией нужно добавить SDK Яндекс Игр: полноэкранную рекламу между игровыми сессиями, rewarded-рекламу по желанию игрока, облачные сохранения и таблицу лидеров. Текущий MVP не требует внешних библиотек и готов к упаковке в iframe после подключения SDK.
